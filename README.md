用于Windows的 Phinger Compact22 小号高清版

原作者：Philipp Schaffrath (phisch)
来源：https://github.com/phisch/phinger-cursors
许可：CC BY-SA 4.0，见 LICENSE。
移植改动：使用原生 24px 设计，矢量缩放至 22px 比例，置于 32px 画布（比 Compact 版缩小约 8.3%）；静态 CUR 提供 32/48/64/96/128 多分辨率，动画 ANI 使用针对 150% 缩放的原生 48px 帧。

打开 Dark-Compact22 或 Light-Compact22 文件夹，右键 install.inf 安装。
Win+R 输入 main.cpl，在指针方案中选择 Phinger Dark Compact22 或 Phinger Light Compact22，再应用。

相对于旧版缩小图形占比；多个尺寸直接由 SVG 渲染，供 Windows 选择。
已通过原生文件加载和多尺寸热点检查；实际缩放选择及使用手感仍需在桌面验收。
